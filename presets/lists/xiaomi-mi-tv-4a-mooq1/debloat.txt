# Xiaomi Mi TV 4A (MiTV-MOOQ1, codename tarzan), Android TV 10, SDK 29, firmware QTG3.200305.006.2591
# The list behind the itsluminous fork (https://github.com/itsluminous/cleanyourtv): derived from
# examples/xiaomi-mi-tv-4a/debloat.txt and examples/xiaomi-mitv-mooq0/debloat.txt (same QTG3 firmware line),

# Apply:   setup debloat --preset xiaomi-mi-tv-4a-mooq1
# Undo:    setup restore --preset xiaomi-mi-tv-4a-mooq1
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
